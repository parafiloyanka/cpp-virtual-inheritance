# C++ Virtual Inheritance: Genealogy Tree 🌳

Цей проєкт демонструє реалізацію складних концепцій об'єктно-орієнтованого програмування у C++ на прикладі побудови генеалогічного дерева видатної української письменниці Лесі Українки.

## ⚙️ Досліджувані концепції ООП
- **Множинне успадкування (Multiple Inheritance):** Клас `LesyaUkrainka` одночасно успадковує властивості двох батьківських класів (`PetroKosach` та `OlhaDrahomanova`).
- **Віртуальне успадкування (Virtual Inheritance):** Використання ключового слова `virtual` (наприклад, `public virtual Person`) для уникнення дублювання базового класу. Це вирішує класичну "проблему ромба", гарантуючи, що в ієрархії існує лише один екземпляр класу `Person`.
- **Життєвий цикл об'єктів:** Відстеження порядку виклику конструкторів та деструкторів під час створення базових та похідних класів.
- **Інкапсуляція:** Захист базових даних (`protected`) та доступ до них через `getter`-методи.
